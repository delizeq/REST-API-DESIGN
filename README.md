# 🎮 Esports Watch

Сайт для тих, хто дивиться кіберспортивні турніри з **CS2** та **Dota 2**.

## Ідея

Зараз розклад матчів розкиданий по різних сайтах і чатах. Тут усе в одному місці: можна подивитись, які є турніри, які команди грають і коли саме буде потрібний матч.

Знайти матч можна через календар: обираєш день і бачиш, що в цей день грається. Також є сторінки ігор, турнірів і команд, а ще пошук і фільтри.

Без акаунта можна дивитись загальні списки. Якщо зареєструватись, відкривається детальна інформація про матчі (рахунок, формат, статус), можна підписуватись на турніри й команди та відмічати матчі, які вже подивився. Усе це видно в профілі.

Турніри й матчі додають організатори та адміни. На старті в базі вже є тестові дані (кілька ігор, команд, турнірів і матчів).

## Ролі

| Роль | Що може |
|---|---|
| Без логіну | дивитись списки ігор, турнірів, команд і матчів, шукати, фільтрувати, користуватись календарем |
| Глядач | те саме + деталі матчів, профіль, підписки, переглянуті матчі |
| Організатор | усе, що глядач + створювати, змінювати й видаляти **свої** турніри та їхні матчі |
| Адмін | усе, що організатор, але для всіх турнірів і матчів + керувати іграми та командами |

## Загальне

- Дані передаються у форматі JSON.
- Для запитів, які потребують входу, в заголовку передається токен: `Authorization: Bearer <token>`.
- Помилки повертаються у вигляді:

```json
{ "error": "Опис помилки" }
```

## Ендпоінти

### 🔐 Авторизація

#### POST /auth/register
Реєстрація нового користувача (одразу з роллю глядача).
- **Тіло запиту:**
```json
{
  "nickname": "cs_fan",
  "email": "viewer@example.com",
  "password": "mypassword123"
}
```
- **Статус:** `201 Created`; `400` якщо дані некоректні; `409` якщо такий email уже є.
- **Тіло відповіді:**
```json
{
  "id": 5,
  "nickname": "cs_fan",
  "email": "viewer@example.com",
  "role": "viewer"
}
```

#### POST /auth/login
Вхід в акаунт.
- **Тіло запиту:**
```json
{
  "email": "viewer@example.com",
  "password": "mypassword123"
}
```
- **Статус:** `200 OK`; `400` якщо не вказано email або пароль; `401` якщо дані невірні.
- **Тіло відповіді:**
```json
{
  "token": "abc123...",
  "user": { "id": 5, "nickname": "cs_fan", "role": "viewer" }
}
```

#### GET /users/me
Отримати дані свого профілю. Потрібен вхід.

Редагувати свої дані. Потрібен вхід.
- **Тіло запиту:**
```json
{
  "nickname": "cs_fan_new",
  "about": "Дивлюсь CS2 та Dota 2"

```
- **Статус:** `200 OK`; `400` якщо дані некоректні; `401` якщо не залогінений.
- **Тіло відповіді:** оновлений профіль (такий самий, як у `GET /users/me`).

### 🕹️ Ігри

#### GET /games
Список усіх ігор. Вхід не потрібен.
- **Параметри:** `search` (пошук за назвою).
- **Статус:** `200 OK`.
- **Тіло відповіді:**
```json
[
  { "id": 1, "name": "CS2", "description": "Командний шутер 5 на 5" },
  { "id": 2, "name": "Dota 2", "description": "MOBA, 5 на 5" }
]
```

#### GET /games/{id}
Одна гра. Вхід не потрібен.
- **Статус:** `200 OK`; `404` якщо гри немає.
- **Тіло відповіді:**
```json
{ "id": 1, "name": "CS2", "description": "Командний шутер 5 на 5" }
```

Додати гру. Тільки адмін.
- **Тіло запиту:**
```json
{ "name": "Valorant", "description": "Тактичний шутер" }
```

- **Тіло відповіді:** створена гра з `id`.

#### PUT /games/{id}

- **Статус:** `200 OK`; `400`; `401`; `403`; `404`.
- **Тіло відповіді:** оновлена гра.

#### DELETE /games/{id}
Видалити гру. Тільки адмін.
- **Статус:** `204 No Content`; `401`; `403`; `404`.
- **Тіло відповіді:** немає.

### 🏆 Турніри

#### GET /tournaments
Список турнірів. Вхід не потрібен.
- **Параметри:**
  - `search`: пошук за назвою
  - `game`: id гри
  - `status`: `upcoming`, `ongoing` або `finished`
  - `sort`: `start_date_asc`, `start_date_desc`, `prize_desc`
- **Приклад:** `GET /tournaments?game=1&status=ongoing&sort=prize_desc`
- **Статус:** `200 OK`.
- **Тіло відповіді:**
```json
[
  {
    "id": 7,
    "name": "Winter Cup CS2",
    "game_id": 1,
    "start_date": "2026-11-01",
    "end_date": "2026-11-07",
    "prize_pool": 5000,
    "status": "upcoming"
  }
]
```

#### GET /tournaments/{id}
Один турнір. Вхід не потрібен.
- **Статус:** `200 OK`; `404`.
- **Тіло відповіді:** один турнір (поля як вище + `created_by`).

#### POST /tournaments
Створити турнір. Організатор або адмін.
- **Тіло запиту:**
```json
{
  "name": "Winter Cup CS2",
  "game_id": 1,
  "start_date": "2026-11-01",
  "end_date": "2026-11-07",
  "prize_pool": 5000,
  "status": "upcoming"
}
```
- **Статус:** `201 Created`; `400` некоректні дані (наприклад, кінець раніше за початок); `401`; `403`; `404` якщо гри з таким `game_id` немає.
- **Тіло відповіді:**
```json
{
  "id": 7,
  "name": "Winter Cup CS2",
  "game_id": 1,
  "start_date": "2026-11-01",
  "end_date": "2026-11-07",
  "prize_pool": 5000,
  "status": "upcoming",
  "created_by": 5
}
```

#### PUT /tournaments/{id}
Змінити турнір. Організатор (тільки свій) або адмін.
- **Тіло запиту:** такі самі поля, як у `POST /tournaments`.
- **Статус:** `200 OK`; `400`; `401`; `403`; `404`.
- **Тіло відповіді:** оновлений турнір.

#### DELETE /tournaments/{id}
Видалити турнір. Організатор (тільки свій) або адмін.
- **Статус:** `204 No Content`; `401`; `403`; `404`.
- **Тіло відповіді:** немає.

#### GET /tournaments/{id}/matches
Усі матчі турніру. Вхід не потрібен (коротка інформація).
- **Параметри:** `sort` (`date_asc`, `date_desc`).
- **Статус:** `200 OK`; `404` якщо турніру немає.
- **Тіло відповіді:** список матчів (як у `GET /matches`).

### ⚔️ Матчі

#### GET /matches
Список матчів (коротко). Вхід не потрібен.
- **Параметри:**
  - `date`: один день з календаря, наприклад `2026-11-03`
  - `from`, `to`: діапазон дат
  - `tournament`: id турніру
  - `team`: id команди
  - `game`: id гри
  - `status`: `upcoming`, `live`, `finished`
  - `sort`: `date_asc`, `date_desc`
- **Приклад:** `GET /matches?date=2026-11-03&game=1`
- **Статус:** `200 OK`.
- **Тіло відповіді:**
```json
[
  {
    "id": 12,
    "tournament_id": 7,
    "team1": "NAVI",
    "team2": "Team Spirit",
    "start_time": "2026-11-03T18:00:00",
    "status": "upcoming"
  }
]
```

#### GET /matches/{id}
Деталі матчу. **Тільки для авторизованих.**
- **Статус:** `200 OK`; `401` якщо не залогінений; `404`.
- **Тіло відповіді:**
```json
{
  "id": 12,
  "tournament_id": 7,
  "team1": "NAVI",
  "team2": "Team Spirit",
  "start_time": "2026-11-03T18:00:00",
  "format": "bo3",
  "score": "2:1",
  "status": "finished"
}
```

#### POST /matches
Створити матч. Організатор (у своєму турнірі) або адмін.
- **Тіло запиту:**
```json
{
  "tournament_id": 7,
  "team1_id": 1,
  "team2_id": 2,
  "start_time": "2026-11-03T18:00:00",
  "format": "bo3"
}
```
- **Статус:** `201 Created`; `400` некоректні дані (наприклад, однакові команди); `401`; `403`; `404` якщо турніру чи команди немає.
- **Тіло відповіді:** створений матч з `id`, `score: null` і `status: "upcoming"`.

#### PUT /matches/{id}
Змінити матч, зокрема вписати рахунок. Організатор (свій турнір) або адмін.
- **Тіло запиту:**
```json
{
  "start_time": "2026-11-03T18:00:00",
  "format": "bo3",
  "score": "2:1",
  "status": "finished"
}
```
- **Статус:** `200 OK`; `400`; `401`; `403`; `404`.
- **Тіло відповіді:** оновлений матч.

#### DELETE /matches/{id}
Видалити матч. Організатор (свій турнір) або адмін.
- **Статус:** `204 No Content`; `401`; `403`; `404`.
- **Тіло відповіді:** немає.

## Схема бази даних

Таблиці:
- **users**: id, nickname, email, password, about, role
- **games**: id, name, description
- **tournaments**: id, name, game_id, start_date, end_date, prize_pool, status, created_by
- **teams**: id, name, country, description
- **matches**: id, tournament_id, team1_id, team2_id, start_time, format, score, status
- **subscriptions**: id, user_id, target_type, target_id
- **watched_matches**: id, user_id, match_id, watched_at

Основні зв'язки:
- одна гра має багато турнірів;
- один турнір має багато матчів;
- у матчу дві команди;
- користувач створює турніри (`created_by`), має багато підписок і відміток переглянутих матчів.
