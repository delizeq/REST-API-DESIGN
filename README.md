# Esports Watch

Esports Watch — проєкт для перегляду інформації про кіберспортивні матчі з CS2 та Dota 2.

## Мета проєкту

Зібрати інформацію про ігри, команди, турніри та матчі в одному місці. Користувач зможе переглядати розклад матчів, знаходити потрібні турніри та команди й фільтрувати інформацію.

## Основні сутності

- **Games** — кіберспортивні ігри.
- **Teams** — команди.
- **Tournaments** — турніри.
- **Matches** — матчі між командами.

## Технології

- Python
- Django REST Framework
- SQLite під час локальної розробки
- HTML, CSS та JavaScript для вебінтерфейсу

## Формат API

API передає дані у форматі JSON та використовує HTTP-методи для отримання, створення, редагування й видалення ресурсів.

## Запуск

Інструкції зі встановлення, запуску сервера та доступні ендпоїнти описані в README основної реалізації бекенду в гілці `feature/crud-api`.
