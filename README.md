# Esports Watch — REST API

Esports Watch — REST API для перегляду інформації про кіберспортивні ігри, команди, турніри та матчі CS2 і Dota 2. API повертає дані у форматі JSON і може використовуватися фронтендом сайту.

## Технології

- Python
- Django
- Django REST Framework
- SQLite
- HTML, CSS та JavaScript для фронтенду

## Можливості API

- Отримання списку ігор та інформації про окрему гру.
- Отримання списку команд та інформації про команду.
- Отримання списку турнірів та інформації про турнір.
- Перегляд матчів і деталей окремого матчу.
- Отримання матчів певної команди або турніру.
- Фільтрація та сортування матчів відповідно до реалізованих параметрів.

## Встановлення та запуск

### 1. Перейти до папки проєкту

Клонуй репозиторій і відкрий його папку в терміналі.

### 2. Створити віртуальне середовище

```bash
python -m venv venv
```

Активувати середовище у Windows Git Bash:

```bash
source venv/Scripts/activate
```

### 3. Встановити залежності

```bash
pip install -r requirements.txt
```

### 4. Виконати міграції бази даних

```bash
python manage.py migrate
```

### 5. Запустити сервер

```bash
python manage.py runserver
```

Після запуску локальний сервер Django буде доступний за адресою:

`http://127.0.0.1:8000/`

## Ендпоінти

У наведеній нижче таблиці перелічені основні маршрути API. Доступні HTTP-методи залежать від реалізації відповідного маршруту.

| Метод | URL | Опис |
|---|---|---|
| GET | `/games/` | Список ігор |
| GET | `/games/<id>/` | Інформація про гру |
| GET | `/games/<id>/tournaments/` | Турніри певної гри |
| GET | `/teams/` | Список команд |
| GET | `/teams/<id>/` | Інформація про команду |
| GET | `/teams/<id>/matches/` | Матчі певної команди |
| GET | `/tournaments/` | Список турнірів |
| GET | `/tournaments/<id>/` | Інформація про турнір |
| GET | `/tournaments/<id>/matches/` | Матчі певного турніру |
| GET | `/matches/` | Список матчів |
| GET | `/matches/<id>/` | Інформація про матч |

Замість `<id>` потрібно вказати числовий ідентифікатор запису.

## Фільтрація та сортування матчів

Для списку матчів передбачені такі приклади запитів:

```http
GET /matches/
GET /matches/?sort=date_asc
GET /matches/?date=2026-11-01
```

- `date` — дата, за якою потрібно відфільтрувати матчі.
- `sort=date_asc` — сортування за датою від раніших матчів до пізніших.

Параметри та їхня поведінка залежать від поточної реалізації API.

## Структура даних

Основні сутності проєкту:

- **Game** — кіберспортивна гра.
- **Team** — команда.
- **Tournament** — турнір, пов'язаний із грою.
- **Match** — матч між двома командами в межах турніру.

Матчі пов'язані з командами й турнірами, а турніри — з відповідними іграми.

## Перевірка API

API можна перевіряти за допомогою браузера, Django REST Framework Browsable API або Postman.

Перед перевіркою запусти сервер і переконайся, що міграції бази даних виконані.
